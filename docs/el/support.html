Επικοινωνία

Για να αναφέρετε ένα σφάλμα, να προτείνετε μια λειτουργία ή να κάνετε μια ερώτηση, στείλτε μας email. Διαβάζουμε κάθε μήνυμα.

Email: leeo@kakao.com

Αν έχετε λογαριασμό GitHub, μπορείτε επίσης να ανοίξετε ένα issue στο GitHub.

Αν αναφέρετε το μοντέλο της συσκευής, την έκδοση iOS και την έκδοση της εφαρμογής (Ρυθμίσεις ▸ Γενικά ▸ Αποθηκευτικός χώρος iPhone ▸ Externalize), θα απαντήσουμε πιο γρήγορα. Δεν χρειάζεται ποτέ να μας πείτε τι γράφουν οι σημειώσεις σας.

Συχνές ερωτήσεις

Πώς αποθηκεύω μια σημείωση;

Πατήστε + στη γωνία στο πάνω μέρος, επιλέξτε τύπο (Στάθμευση, Ντουλάπι, Δωμάτιο, Κωδικός, Σημείωση), πληκτρολογήστε την τιμή και πατήστε Αποθήκευση. Επιλέξτε αν θα ξεχαστεί μετά από 1 ώρα, 8 ώρες ή 24 ώρες.

Μια σημείωση εξαφανίστηκε. Μπορώ να την ανακτήσω;

Όχι. Όταν λήξει ο χρόνος της, η σημείωση διαγράφεται οριστικά από τη συσκευή σας. Δεν υπάρχει αρχείο ούτε αντίγραφο ασφαλείας. Αν τη χρειάζεστε περισσότερο, σύρετε τη σημείωση προς τα δεξιά λίγο πριν λήξει, για να τη διατηρήσετε για άλλες 24 ώρες.

Πώς τη βάζω στην οθόνη κλειδώματος;

Πατήστε παρατεταμένα την οθόνη κλειδώματος, πατήστε Προσαρμογή ▸ Οθόνη κλειδώματος, πατήστε την περιοχή των widget και προσθέστε το widget του Externalize. Υπάρχει επίσης ένα μικρό widget για την αρχική οθόνη.

Μπορώ να αποθηκεύω με το Siri;

Πείτε «Θυμήσου στο Externalize». Μπορείτε επίσης να χρησιμοποιήσετε την ενέργεια Να θυμάσαι στην εφαρμογή Συντομεύσεις ή να την αντιστοιχίσετε στο Κουμπί ενέργειας από τις Ρυθμίσεις ▸ Κουμπί ενέργειας.

Πώς αντιγράφω μια τιμή;

Πατήστε μια σημείωση στη λίστα και η τιμή της αντιγράφεται. Σύρετε προς τα αριστερά για να τη διαγράψετε αμέσως.

Θα μεταφερθούν οι σημειώσεις μου σε νέο iPhone;

Όχι. Οι σημειώσεις αποθηκεύονται μόνο σε αυτή τη συσκευή και δεν στέλνονται ποτέ στο iCloud ή σε κάποιον διακομιστή. Αν διαγράψετε την εφαρμογή, διαγράφονται και οι σημειώσεις σας.

Ποιες συσκευές υποστηρίζονται;

iPhone με iOS 17 ή νεότερο.

Υπάρχει κάτι που πρέπει να αγοράσω;

Όχι. Όλες οι λειτουργίες είναι δωρεάν, χωρίς όριο στον αριθμό των σημειώσεων που κρατάτε.
