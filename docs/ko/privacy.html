소개 지원 개인정보처리방침

요약

뇌모리는 개인정보를 수집하지 않습니다. 계정도, 로그인도, 광고도, 외부 분석 도구도 없습니다. 입력한 메모는 사용자의 iPhone 안에만 저장되고, 정해진 시간이 지나면 스스로 삭제됩니다. 앱을 몇 명이 쓰는지 알고 오류를 고치기 위해 익명 사용 통계와 오류 보고만 보냅니다.

1. 수집하는 정보

개발자는 이름, 연락처, 위치, 메모 내용 같은 개인정보를 수집하지 않습니다. 기기 밖으로 나가는 것은 아래 ‘3. 익명 사용 통계’에 적은 항목뿐입니다.

2. 기기에 저장되는 정보

사용자가 직접 입력한 메모(종류, 값, 이름, 만든 시각, 삭제될 시각)는 앱과 위젯이 함께 읽을 수 있도록 기기 안의 앱 전용 저장 공간에만 보관됩니다. 이 정보는 개발자를 포함한 누구에게도 전송되지 않습니다.

  • 메모는 사용자가 고른 시간(1시간, 8시간, 24시간)이 지나면 자동으로 영구 삭제됩니다.
  • 사용자는 언제든 메모를 밀어서 즉시 삭제할 수 있습니다.
  • 앱을 삭제하면 저장된 메모도 모두 삭제됩니다.

이 밖에 앱은 처음 설치한 시각과 실행 횟수를 기기에 기록합니다. 이 값은 아래 익명 사용 통계에 쓰이며, 앱을 삭제하면 함께 지워집니다.

기기 백업을 켜 두었다면 iOS가 기기 백업의 일부로 앱 데이터를 포함할 수 있으며, 이는 Apple의 개인정보처리방침을 따릅니다.

3. 익명 사용 통계

앱을 몇 명이 쓰는지 알고 오류를 고치기 위해, 뇌모리는 다음 익명 통계를 Apple iCloud(CloudKit)로 보냅니다. 개발자만 읽습니다.

  • 설치할 때 만든 무작위 ID (사용자·Apple ID·기기·다른 앱과 연결되지 않으며, 다시 설치하면 바뀝니다)
  • 앱 버전, iOS 버전, 지역·언어 설정
  • 앱을 연 횟수와 앱을 연 날, 설치한 날짜와 설치 후 지난 날수
  • 앱이 멈추거나 종료된 오류 보고 (앱 버전, iOS 버전, 기기 종류, 오류의 기술 정보)

이름, 연락처, 위치, 메모 내용은 포함하지 않습니다. iCloud에 로그인되어 있을 때만 보냅니다.

4. Siri와 단축어

“뇌모리에 기억해”처럼 Siri나 단축어로 메모를 저장하면, 음성 인식은 Apple이 처리합니다. 뇌모리는 그 결과로 전달된 텍스트만 받아 기기에 저장합니다. Siri의 데이터 처리는 Apple 개인정보처리방침을 따릅니다.

5. 클립보드

메모를 탭했을 때만 그 값을 클립보드에 복사합니다. 뇌모리는 클립보드 내용을 읽지 않습니다.

6. 제3자 제공 및 추적

광고, 외부 분석, 추적 도구나 제3자 SDK를 쓰지 않습니다. 익명 사용 통계와 오류 보고는 개발자가 직접 만든 공용 라이브러리(LeeoKit)가 Apple iCloud로 보내며, 어떤 정보도 제3자에게 제공하거나 판매하지 않습니다. 사용자를 추적하지 않습니다.

7. 아동의 개인정보

뇌모리는 누구의 개인정보도 수집하지 않으므로, 만 14세 미만 아동의 개인정보도 수집하지 않습니다. 익명 사용 통계도 누구의 것인지 알 수 없습니다.
